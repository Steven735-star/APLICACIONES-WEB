PROJECT DESCRIPTION

This project consists of a personal university website developed using
only HTML5. The objective of the workshop is to practice the fundamental
structure of HTML documents, semantic HTML elements, navigation, tables,
forms, lists, links, and images.

The website is composed of multiple interconnected pages that provide
academic and personal information.


ACTIVITIES COMPLETED

1. HOME PAGE

The home page (index.html) contains a brief student profile including
my name, degree program, semester, personal description, profile image,
and academic interests.

Semantic HTML5 elements such as header, nav, main, section, article,
and footer were used to organize the content.


2. COURSES

The courses page (courses.html) contains information about the courses
I am currently taking during Semester 8.

For each course, the page includes:
- Course name
- Course code
- Instructor
- Main topics
- Topics I expect to learn

Ordered lists, unordered lists, headings, paragraphs, and external
links were used.


3. WEEKLY SCHEDULE

The schedule page (schedule.html) contains my weekly university class
schedule.

The schedule was created using an HTML table. The table includes the
days of the week, class times, course names, classrooms, and university
buildings.

The rowspan and colspan attributes were used to represent classes that
occupy multiple hours and to organize the table header.


4. CONTACT FORM

The contact page (contact.html) contains an HTML form created to
practice different form elements and input types.

The form includes:
- Name
- Email
- Date of birth
- Degree program
- Semester
- Reason for contact
- Message
- Acceptance checkbox
- Submit button
- Reset button

The form does not use a backend or database and does not store the
submitted information.


5. HOBBIES

The hobbies page (hobbies.html) contains information about some of my
personal interests, including playing football, going on motorcycle
trips, and spending time with friends.

The information is organized using semantic HTML elements, paragraphs,
and lists.


6. RESOURCES

The resources page (resources.html) contains useful academic and
programming resources.

It includes links to GitHub, MDN Web Docs, Python documentation, and
Git documentation. External links are configured to open in a new
browser tab.


7. WEBSITE NAVIGATION

All pages are interconnected through a navigation menu. This allows
the user to move between Home, Courses, Schedule, Hobbies, Resources,
and Contact.


8. LOCAL WEB SERVER

The website was configured to run locally using the Apache web server.

The local domain:

http://workshop1.webapp

was mapped to localhost using the operating system hosts file and an
Apache Virtual Host was configured to serve the project directory.
